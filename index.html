03 / 06 — What I Do

Where I spend my time

The areas I focus on most — from API architecture to design implementation.

01

Backend Engineering

Designing and building RESTful APIs with Node.js and Express. Authentication systems using JWT and session tokens. Schema design in MongoDB with Mongoose. Middleware, error handling, and data validation.

02

Frontend Development

Building user interfaces with React and Next.js. Component architecture, state management, routing, and form handling. Connecting frontends cleanly to REST APIs. Responsive, accessible markup.

03

Full Stack Products

Taking a feature from database schema to deployed UI. Multi-role systems, CRUD operations, file uploads, and data relationships. End-to-end thinking from first endpoint to final interaction.

04

Design Implementation

Translating Figma designs into pixel-accurate HTML and CSS. Semantic markup, cross-browser layouts, and component structuring. Bridging the gap between how it looks in design and how it works in code.

05

Authentication & Security

Implementing secure authentication flows — JWT tokens, refresh token rotation, password hashing with bcrypt, protected routes, and role-based access control. Keeping user data safe by default.

06

API Architecture

Structuring RESTful APIs with clean route separation, controller logic, and service layers. Designing for consistency, clarity, and maintainability — APIs that a team member can understand and extend.
